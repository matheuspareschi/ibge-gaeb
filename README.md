# Levantamento Espiritual GAEB

Página de questionário para os adolescentes do GAEB (uma subárea por tela).

- `perguntas.js` — todas as perguntas, escalas, abertura e encerramento. É o único arquivo a editar para mudar o questionário.
- `index.html` — a página (visual e lógica).
- O envio usa o Formspree: cole o endereço do formulário em `GAEB_CONFIG.formspree` no `perguntas.js`.

As respostas **não são guardadas neste repositório**: vão por e-mail (Formspree) só para a liderança. Não coloque e-mails nem respostas aqui.
